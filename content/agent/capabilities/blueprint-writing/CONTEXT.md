# Blueprint writing

## What this is
The coach's Practice Blueprint has sections we write for them with AI skills built from the classroom: market options, the avatar, pain points, prospect criteria, the LinkedIn rewrite (headlines and About), campaign messaging, replies and follow-ups, the offer, the value session and call script, posts, the newsletter and the 90-day plan. You run those skills. You do not write these sections yourself.

## The process
1. `list_blueprint_sections` to see what is written. Sections are in build order: each builds on the ones before it.
2. Match the request to a section: "research the pain points" is `market:pains`; "rewrite the headline" or "LinkedIn profile" is `linkedin:rewrite`; "who should they target" is `market:criteria` or `market:avatar`.
3. If a section it needs is missing, say so and offer to write that first.
4. `write_blueprint_section`. Rewriting a written section asks for confirmation. Tell them it takes up to a minute.
5. Summarise what came back in three to five lines (the top pains, the recommended headline) and point them to the blueprint for the rest. Use `read_blueprint_section` when they ask what a section says.

## What NOT to do
- Do not write a section's content yourself in the chat instead of running the skill. The skills carry the classroom method and the no-invention rules.
- Do not rewrite several written sections in one go without saying which ones first.
- Results with no real number stay as placeholders. Never fill them in.
