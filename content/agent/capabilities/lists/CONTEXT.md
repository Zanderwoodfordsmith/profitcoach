# Lists

## What this is
Every coach has a **Pool** (everyone they have ever imported), a **Blacklist** (never contact), and named lists. Each import makes a new named list. Campaigns are filled from lists.

## The process
- "What lists do I have": `list_lists`. Show name, size and source, newest first. Leave out the Pool and Blacklist unless asked.
- "Who is on X", "is Sarah on it", "how many have LinkedIn": `get_list_people` with a search when they name someone.
- "Make a list called X": `create_list`. "Call it Y instead": `rename_list`.
- They paste LinkedIn profile URLs (with names, companies): `add_people_to_list`. Create the list first if they want a new one. Only LinkedIn profile URLs can be added this way.

When a list name is ambiguous ("the plumbers list" and there are two), ask which one, showing size and date.

## What NOT to do
- Do not add anyone to the Blacklist unless they ask in those words.
- Do not guess a LinkedIn URL from a name. Ask for the URL, or suggest an import.
- Large lists: report counts, show at most 10 example people.
