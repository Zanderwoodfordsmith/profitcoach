Toyota have been benefiting from material and information flow mapping (value stream mapping) since the 1940s.

Taiichi Ohno could not see waste at a glance, especially across a geographical area. He developed material and information flow mapping as a standard method for mapping the flows visually. It became the standard basis for designing improvements at Toyota, a common language, and one of their business planning tools.

Value stream mapping (VSM) is now used throughout the world, in many businesses, to plan strategically. VSM is the start of any lean transformation:

"Where you can flow, you flow. Where you can't flow, you pull."

## What is a value stream map?

A value stream map is a diagram of all the actions (both value-added and non-value-added) needed to bring a product from raw material through to the arms of the customer.

Before you begin mapping, you need to identify a product family. Use a product family matrix to do this.

![A product family matrix](/beyondlean/blog/value-stream-mapping/product-family-matrix.jpg)

## Seven steps to a current state value stream map

1. The diagram needs to be on one sheet of paper.
2. Use the standard format for the diagram.
3. Use the standard symbols for the diagram.
4. Capture all of the data yourself.
5. Walk, understand and validate the process.
6. Involve as many people as practical.
7. Use paper and pencil.

You should end up with a value stream map that looks similar to this:

![An example of a current state value stream map](/beyondlean/blog/value-stream-mapping/current-state-map.jpg)

## From current state to future state

- Collect data across a value stream.
- Use the seven steps to draw a current state value stream map.
- Draw a future state map.
- Identify your material and information loops.
- Decide the order in which to tackle the loops.
- Write the tactical implementation plan.

For the plan:

- Set objectives for each loop as needed to achieve the future state.
- Set measurable goals for each objective.
- Set an order of work within each loop.
- Set milestones and write up the plan.
- Get formal agreement from everyone concerned.

The leader of each work stream should produce their own schedule, showing how they will achieve each goal by its milestone.

## Value stream map or process map?

One final question many people ask: what is the difference between a value stream map and a process map?

![Value stream mapping compared with process mapping](/beyondlean/blog/value-stream-mapping/vsm-vs-process-mapping.jpg)

A value stream map considers the whole value stream. It finds the non-value-added steps between processes. The improvements it leads to are usually significant but hard to achieve, and it lets you plan long-term strategy.

A process map concentrates on a single process. It finds the non-value-added steps within that process. The improvements it leads to are usually small but very easy to put in place, and it helps with short-term, tactical planning.
