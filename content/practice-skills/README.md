# Practice skills

The method files BCA's Practice Blueprint uses to write each section for a coach.
Each file is one area. The build route loads `_shared.md`, the brand writing
rules (`content/ai-knowledge/writing-rules.md`), and the file named by the
section in `src/lib/practiceKnowledge/skills.ts`.

Sources: the BCA classroom (Get Calls, Win Clients, Coach Action Plan), the
connector campaign templates, Pam's value session, and live campaigns.

Edit these freely. Keep them short and practical. No em dashes.
