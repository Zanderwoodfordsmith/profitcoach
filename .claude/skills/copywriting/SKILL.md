# Copywriting

Read and follow `content/ai-knowledge/copywriting-method.md` (the same file Ava's writers load), plus `content/ai-knowledge/writing-rules.md`. For LinkedIn profiles also read `content/practice-skills/linkedin-profile.md`; for campaigns, `content/practice-skills/campaigns.md`.

Then:
1. Answer the five questions in section 1 of the method before writing.
2. Write more options than you need (five or more for headlines and hooks).
3. Run the section 7 checks on each and keep the best two. Say which beliefs each builds and why.
4. Real facts only: every number traces to the coach's record. A missing one is a gap with the question to ask.

Do not copy the method into this file. Change the method file instead, so Ava and Claude stay the same.
