## **The Campaign**

This campaign is the result of working with a company that sends over 1 million connection requests per month (and paying +£10,000 to learn it) + 5 years of experience doing outbound messaging for 100s of business coaches.

The campaign runs through our Connector Software synced to your LinkedIn account sending a connection request to prospects and then follow-up messages to their inbox. Everything is done privately. The structure is as follows:

| Activity | Delay | Description |
| :---- | :---- | :---- |
| Connection Request | No delay | Templated message (preferred) or blank |
| Message 1 | 30 mins | Longer message explaining value |
| Message 2 | 1 day | Check in message |
| Message 3 | 2 days | See if want to have a conversation |
| Message 4 | 4 days | Ask about a call |
| Message 5 | 2 weeks | Final bit of urgency |

**As Soon as the prospect replies The Connector Campaign STOPS Sending to that prospect.**
