# First Campaign — facilitated Ideal Client (single path)

**Decision (Zander, Aug 2026):** Do **not** split this into “short First Campaign” + “longer Ideal Client Studio.” One product path. Facilitated beats live **inside** First Campaign step 3 — not a second thing to discover later.

**Why:** “Do the short version now, then the long version later” is confusing and pointless. Coaches should go through the Ideal Client properly **once**, in the same wizard that gets them to messages and a starter list.

**Evidence:** Pam’s 1:1 transcripts (`.ica-research/session-transcripts/`, summary in `.ica-research/pam-icp-facilitation-pattern.md`) still define *how* to facilitate — generate a bit → confirm/amend → next bit. We keep that rhythm; we just don’t productise it as a separate app.

**Related:** [First Campaign Setup](./first-campaign-setup.md), [Avatar schema](./ideal-client-avatar-schema.md).

---

## 1. One wizard, five steps (unchanged shape)

```
1 LinkedIn
2 Choose ICP
3 Ideal Client   ← facilitated Profile → Avatar (this doc)
4 Messages
5 Starter list
```

Step 3 gets deeper. Steps 1–2 and 4–5 stay as they are. No second nav item, no “deepen later” fork.

Newsletter / marketing assets (Pam’s Call 2) can come **after** First Campaign is complete — that’s a later chapter of the same journey, not a parallel Ideal Client product.

---

## 2. Middle ground (what we build)

Not a one-shot wall of text. Not a 45-minute second product.

**Inside step 3 only:**

| Phase | Coach experience | Gate |
|-------|------------------|------|
| **A. Profile generate** | Progress bars; Profile only | Draft ready |
| **B. Profile confirm** | Walk a **small number of sections** (not every micro-field). Agree / edit / remove / add | Coach locks Profile |
| **C. Avatar generate** | Progress bars; Avatar from **edited** Profile only | Draft ready |
| **D. Avatar confirm** | Walk a few Avatar beats (persona + problem + quote/hooks). Confirm → save to brain | Coach continues to Messages |

Hard rule from Pam (keep):

> Use the **edited** Profile to create the Avatar. Never generate Avatar from the unedited first draft.

Optional later (same step, not a new product): short Pam/Zander clip at the top of A and C; voice on “does this sound like them?”.

---

## 3. What to walk (keep it lean)

Pam’s richest call walks many sections. Product middle ground = **enough to feel facilitated, few enough to finish**.

### Profile confirm (pick ~4 cards, not 10)

1. Target market & titles (quick)  
2. Pains **in their words** (highest edit rate — always include)  
3. Dreams / desired outcomes  
4. Not a fit + positioning statement  

Fears / failures / suspicions can sit behind “Show more” or land on the Avatar pass — don’t force a full psychology exam before they can message anyone.

### Avatar confirm (pick ~3–4 cards)

1. Headline + name + who they are  
2. Specific problem (quoted)  
3. Quote + messaging hooks (what feeds step 4)  
4. Optional: reality / monologue behind “Show more”

Brain save stays on the final confirm (section picker), same as today.

---

## 4. How this still matches Pam — without two products

| Pam Call 1 | First Campaign |
|------------|----------------|
| Discover / pick market | Steps 1–2 (LinkedIn + Choose ICP) |
| Profile → confirm → amend | Step 3A–B |
| Avatar from edited profile | Step 3C–D |
| Percolate / marketing later | After step 5 (or a later “Marketing” follow-on) — **not** a second Ideal Client app |

Call 2 (newsletters) is downstream of a finished First Campaign, not a reason to fork Ideal Client into its own product.

---

## 5. Build phases (single path)

### Phase 0 — Stop the one-shot

- Split generate: Profile API, then Avatar API (Avatar requires locked/edited profile)  
- Step 3 UI: generate Profile → section cards → lock → generate Avatar → lighter confirm → brain save → Messages  
- Reuse existing progress bars between generates  

### Phase 1 — Facilitation polish (still same wizard)

- Better Agree / Edit / Add on each card  
- Optional mini video slots on Profile generate and Avatar generate  
- “Show more” for deeper trigger sections without making them mandatory  

### Phase 2 — After First Campaign is done

- Newsletter / marketing from locked avatar (Pam Call 2) as a **next action**, not a parallel Ideal Client Studio  
- Voice optional on confirm cards  

---

## 6. Explicit non-goals

- No separate `/coach/ideal-client` product  
- No “lite avatar now, full studio later” messaging  
- No forcing every Pam section before Messages  
- No Academy / Sales Nav tour inside step 3 (side help only if needed)

---

## 7. Bottom line

**One path.** First Campaign still ends at messages + starter list. Step 3 becomes a short facilitated session (Profile confirm → Avatar from edits), not a dump and not a second product.
